02第 1 步：读图、SIFT、匹配

2.1 原理：描述子与 ratio 判据

SIFT 给每个关键点生成一个 128 维描述子 a，相似度用欧氏距离：

d(a, b) = ‖a − b‖2 = √ Σk=1128 (ak − bk)2 描述子范数实测约 512，距离落在几百量级，所以绝对阈值不可用

匹配不能用"取最近的一个"：那样每个点都会被强行配上对象，实测 4002 个点返回 4002 对，一大半是错的。取最近 d1 与次近 d2，用 Lowe 的 NNDR 判据：

d1d2 < 0.75 正确匹配的特征是唯一的 → 比值小；重复纹理（栏杆、白墙）两个候选一样像 → 比值趋近 1，被剔除。比值无量纲，光照变化不影响它

同一对参考图实测：0.6 / 0.7 / 0.75 / 0.8 / 0.9 分别保留 653 / 899 / 1067 / 1277 / 2030 对。默认 0.75。

03第 2 步：DLT —— RANSAC 的内核求解器

先把定位摆正

本章的 dlt() 不是最终求 H 的方法。它只回答一个更小的子问题：给定 4 对点，怎么算出一个候选 H。真正的 H 由第 4 章的 RANSAC 产生 —— RANSAC 反复调用它造候选、用全部点投票、最后拿内点再调用一次。直接对全部匹配跑一次 DLT 是错的，原因见 4.1。

3.1 H 从哪来：平面约束推出单应

设世界平面 Π: nTX = d（n 为法向，d 为相机到平面距离）。取相机 1 为参考系，两次成像为：

  1. 相机 1：λ1x1 = K1X；相机 2：λ2x2 = K2(RX + t)。K 是 3×3 内参，x 是齐次像素坐标，λ 是深度尺度。
  2. 由 nTX/d = 1，可把平移项改写为 t = t(nTX/d) = (tnT/d)X，于是 t 从"加数"变成"矩阵乘在 X 上"。
  3. 代回：λ2x2 = K2(R + tnT/d)X = K2(R + tnT/d)K1−1(λ1x1)。
  4. 去掉两边深度尺度 λ，得 x2 ~ Hx1，其中
H = K2 ( R + tnT/d ) K1−1 加减号随 t 的定义方向而变，不影响"存在 3×3 线性映射"这一结论

三条有用推论：H 与平面上的图案无关（只由内参、姿态、平面位置决定）；纯旋转时 t=0，H=K2RK1−1 与深度无关（手机原地转头拍全景能无缝拼接）；有平移且场景有纵深时，不同深度对应不同 H，全局单应就会失败——所以校牌能拼、整栋楼不能。

3.2 齐次坐标、8 自由度、最少 4 对点

点 (x, y) 写成 [x, y, 1]T，它表示一条射线：任意 λ≠0，[λx, λy, λ]T 是同一个点。因此：

x′y′1 ~ h11h12h13 h21h22h23 h31h32h33 xy1 "~" 表示相差一个尺度因子。H 与 λH 作用结果完全相同 → 9 个元素只有 8 个自由度

把 h33 固定为 1 后，h 有 8 个未知数；每对匹配点提供 2 个独立方程（下面推），所以 8 ÷ 2 = 4 对点是最少样本。4 对是"恰定"（只能求零空间），有噪声时要用更多点做最小二乘——这正是第 4 步 RANSAC 最后用全部内点重算的理由。

3.3 DLT：把投影式线性化为 Ah = 0

设 h = [h11 h12 h13 h21 h22 h23 h31 h32 h33]T，一对点 (x, y) ↔ (u, v)。

  1. 展开齐次式，记 w = h31x + h32y + h33：
    u = h11x + h12y + h13w ,  v = h21x + h22y + h23w
  2. 交叉相乘消去 w：
    u(h31x + h32y + h33) − (h11x + h12y + h13) = 0
  3. 按 h 的分量整理成行向量内积，并对 v 同理，得到两个线性方程：
    text
    [  x,  y,  1,  0,  0,  0, -u·x, -u·y, -u ] · h = 0
[  0,  0,  0,  x,  y,  1, -v·x, -v·y, -v ] · h = 0
  4. 两行同乘 −1 不改变方程，就得到代码里 A 的那两行：
    text
    [ -x, -y, -1,   0,   0,   0,  u·x, u·y, u ]
[   0,  0,  0,  -x,  -y,  -1,  v·x, v·y, v ]
  5. N 对点堆起来就是 A2N×9 h9×1 = 0；4 对点时 A 是 8×9。

3.4 SVD 为什么取 Vt[-1]

要找非零的 h 使 Ah ≈ 0，必须加尺度约束排除平凡解 h=0：

min ‖Ah‖2   s.t.   ‖h‖ = 1
  1. 对 A 做 SVD：A = UΣVT，其中 σ1 ≥ ⋯ ≥ σ9 ≥ 0。
  2. 令 y = VTh。因 V、U 正交，‖y‖ = ‖h‖ = 1，且 ‖Ah‖2 = ‖UΣy‖2 = ‖Σy‖2。
  3. 展开：‖Σy‖2 = σ12y12 + ⋯ + σ92y92。在 ‖y‖=1 下使其最小，应把全部"质量"放在系数最小的 σ9 项，即 y = (0,…,0,1)T，最小值为 σ92。
  4. 于是 h = V y = V 的最后一列 = VT 的最后一行，即 Vt[-1]；reshape(3,3) 后再除以 h33 归一化。
API 坑

np.linalg.svd(A) 第三个返回值已经是 VT，所以是 Vt[-1]，不要再 .T，也不要写成 Vt[:, -1]。写错不报错，只会让结果悄悄错掉。

3.5 Hartley 归一化与反归一化

像素坐标约 10³，A 里同时有 1、x≈10³、u·x≈10⁶，跨 6 个数量级，SVD 条件数极差，解会系统性偏向大坐标那一侧。先把两组点各自移到质心、各向同性缩放到平均距离 √2：

c = 1N Σpi ,  d̄ = 1N Σ‖pi − c‖ ,  s = √2d̄ s 的选择让归一化后点的平均欧氏距离约等于 √2，A 各列量级拉回同一水平
T = s0−scx 0s−scy 001 ,  p̃ = T p

在归一化坐标下解出 H̃ 后必须还原。推导四步：

  1. p̃1 = T1p1，p̃2 = T2p2；解出 p̃2 ~ H̃ p̃1。
  2. 代入得 T2p2 ~ H̃ T1p1。
  3. 左乘 T2−1：p2 ~ T2−1H̃ T1p1。
  4. 所以 H = T2−1 H̃ T1。T1 作用在输入端，原样留在最右；T2 作用在输出端，取逆放最左。

3.6 一句话说明 DLT 的局限（报告可写）

DLT 最小化的 ‖Ah‖ 是代数误差，没有直接的像素含义；理想目标是几何误差 Σ‖qi − π(Hpi)‖2，它关于 H 非线性，严格解需以 DLT 为初值做 LM 迭代。作业用"RANSAC 挑净内点 + 全部内点重算 DLT"已能把误差压到 1~2 像素，不必实现 LM。

def normalize_points(pts):
    pts = np.asarray(pts, dtype=np.float64)
    c = pts.mean(axis=0)
    d = np.sqrt(((pts - c) ** 2).sum(axis=1)).mean()
    s = np.sqrt(2.0) / d if d > 1e-12 else 1.0
    T = np.array([[s, 0, -s * c[0]],
                  [0, s, -s * c[1]],
                  [0, 0, 1.0]])
    h = np.hstack([pts, np.ones((len(pts), 1))])
    return ((T @ h.T).T)[:, :2], T


def dlt(pts1, pts2):
    p1, T1 = normalize_points(pts1)
    p2, T2 = normalize_points(pts2)
    A = []
    for (x, y), (u, v) in zip(p1, p2):
        A.append([-x, -y, -1, 0, 0, 0, x * u, y * u, u])
        A.append([0, 0, 0, -x, -y, -1, x * v, y * v, v])
    _, _, Vt = np.linalg.svd(np.asarray(A, dtype=np.float64))
    H = np.linalg.inv(T2) @ Vt[-1].reshape(3, 3) @ T1
    return H / H[2, 2]


def apply_h(H, pts):
    pts = np.asarray(pts, dtype=np.float64)
    h = np.hstack([pts, np.ones((len(pts), 1))])
    q = (H @ h.T).T
    w = q[:, 2:3].copy()
    w[np.abs(w) < 1e-12] = 1e-12
    return q[:, :2] / w

对照推导看：A.append 两行 = 3.3 的第 (4) 步；Vt[-1] = 3.4 第 (4) 步；inv(T2) @ ... @ T1 = 3.5 第 (4) 步；apply_h 里除以 w 就是 3.3 第 (1) 步的分母。

04第 3 步：用 RANSAC 求最终 H（核心）

4.1 为什么是 RANSAC，而不是直接 DLT

这是本作业最该讲清楚的一点。第 1 步留下的约 1000 对匹配里通常有 20%~40%（甚至更多）是错的，而 DLT 是最小二乘：它只会给出一个解，并尽量让所有点的残差平方和最小，对离群点毫无抵抗力。一对错匹配的残差可能上千像素，平方后直接主导目标函数，H 被拉到"谁也不太像"的折中位置。

具体到你的数据：4020 个查询点经 ratio 过滤剩 1029 对，实测内点只有 528 对（51.3%），剩下 501 对是错的。把这 1029 对一次性喂给 dlt()，结果必然偏离正确解；而 RANSAC 每次只用 4 对造假设，只要有一轮抽样凑巧全是内点，就能投出正确的 H。

直接 DLT（全部点）RANSAC + DLT（本作业）
输入1029 对，其中 501 对错误每轮随机 4 对，共 3000 轮
对离群点残差平方后主导结果被投票判为外点，不参与建模
鲁棒性无，必须内点接近 100%内点率 50% 仍可靠
输出一个偏掉的 H最优假设 + 内点集 + 精化后的 H

所以两者的关系是外层与内层：RANSAC 决定"用哪些点、迭代多少次、取哪个模型"，DLT 只负责"给 4 对点解出 H"这个动作。最终交付的 H，是最后用全部内点重算的那一个，而不是任何一次 4 点解。

4.2 重投影误差

把图 1 的点用候选 H 投到图 2，与实际对应点比距离，单位是像素：

ei = ‖ π( H pi ) − qi ‖2 ,   ei < τ → 内点 ,  τ = 4 px π(·) = 齐次坐标除第三分量取回像素坐标，就是 apply_h

4.3 迭代次数公式（报告常考）

设内点比例为 w，每次抽 4 对点，置信度目标 p（常取 0.99 或 0.995）。

  1. 一次抽样中 4 个点全是内点的概率 ≈ w4（不放回抽样的严格值略小，作业用 w4 即可）。
  2. 一次抽样失败（至少掺了一个外点）的概率 = 1 − w4。
  3. N 次独立抽样全部失败的概率 = (1 − w4)N。要求它以置信度 p 不发生，即 (1 − w4)N ≤ 1 − p。
  4. 两边取对数：N ln(1 − w4) ≤ ln(1 − p)。注意 ln(1 − w⁴) < 0，除过去不等号反向：
N ≥ ln(1 − p)ln(1 − w4) p = 0.995 时：w = 0.3 → 约 1150 次；w = 0.6 → 约 35 次。内点越多，需要迭代越少

写代码时先固定 3000 次（几秒跑完）完全够交；把上式写成几行按 w 动态更新循环上限就是加分项。报告里要把上面四步推导写出来。

4.4 算法四步

  1. 随机抽 4 对（任意三点共线就重抽，否则 A 秩亏、DLT 无解）。
  2. 用这 4 对跑 dlt() 得到候选 H。
  3. 用 apply_h() 算全部点的 ei，统计内点数；刷新最优就保存 H 与内点掩码。
  4. 迭代结束后用全部内点重跑一次 DLT，再重新统计内点。
第 4 步不能省

4 对点解出的 H 只是"够用来挑内点"，精度远不如几百个内点做最小二乘。少了这步，拼接接缝会明显错位——评分最容易扣这里。

def ransac(pts1, pts2, thresh=4.0, max_iter=3000, seed=0):
    rng = np.random.default_rng(seed)
    n = len(pts1)
    best_H, best_mask, best_cnt = None, np.zeros(n, bool), 0

    for _ in range(max_iter):
        idx = rng.choice(n, 4, replace=False)

        # 任意三点共线 → A 秩亏，重抽
        ok = True
        for a, b, c in [(0, 1, 2), (0, 1, 3), (0, 2, 3), (1, 2, 3)]:
            v1 = pts1[idx[b]] - pts1[idx[a]]
            v2 = pts1[idx[c]] - pts1[idx[a]]
            if abs(v1[0] * v2[1] - v1[1] * v2[0]) < 1.0:
                ok = False
                break
        if not ok:
            continue

        H = dlt(pts1[idx], pts2[idx])
        err = np.linalg.norm(apply_h(H, pts1) - pts2, axis=1)
        mask = err < thresh
        if mask.sum() > best_cnt:
            best_cnt, best_mask, best_H = int(mask.sum()), mask, H

    if best_cnt < 10:
        return None, best_mask

    # 用全部内点重算（对应 4.4 第 4 步）
    H = dlt(pts1[best_mask], pts2[best_mask])
    mask = np.linalg.norm(apply_h(H, pts1) - pts2, axis=1) < thresh
    return H, mask


H, mask = ransac(pts1, pts2)
assert H is not None, "RANSAC 失败，内点不足"
print("内点率: %d/%d = %.1f%%" % (mask.sum(), len(mask), 100 * mask.mean()))
print("H =")
print(np.round(H, 6))

05第 4 步：拼接与平滑融合

5.1 原理：包围盒与平移矩阵

warpPerspective 能把图 1 变换到图 2 的视角，但变换后四角可能落到负坐标，按原尺寸输出会被裁掉。做法：

  1. 取图 1 四角 pi，用 H 变换得 p′i = π(Hpi)；与图 2 四角合并求包围盒 [xmin, xmax] × [ymin, ymax]。
  2. 画布尺寸 ow = xmax − xmin，oh = ymax − ymin；构造平移矩阵把包围盒左上角挪到原点：
T = 10−xmin 01−ymin 001 ,  M = T H ,  warpPerspective(img1, M, (o_w, o_h))

图 2 保持不动，它在画布中的原点是 (−xmin, −ymin)，贴回去即可（代码里做了裁剪保护，防止越界）。

H 的方向

用 pts1 → pts2 解出的 H 是「图 1 → 图 2」，所以变换图 1、把图 2 当基准。若画布尺寸异常巨大或图像跑出画面，先回 2.2 检查 queryIdx/trainIdx 是不是写反了。

5.2 平滑过渡：距离变换羽化

直接把图 2 贴到画布上，接缝处会有一条硬边：两张照片的曝光、白平衡、镜头暗角都不可能完全一致，边界两侧出现亮度突变，人眼对这种台阶极敏感。做法是在重叠区把两张图按权重混合，让过渡带逐渐变化。

权重怎么定？核心想法是：离自己图像边界越远，这一侧的像素越可信（没有被裁切、暗角最轻）。用距离变换算出每个有效像素到本图边界的欧氏距离 d1、d2，再归一化：

w1(x) = d1(x) d1(x) + d2(x) ,   w2 = 1 − w1 融合结果：I(x) = w1I1(x) + w2I2(x)

这个式子有三个好处，正好对应实现里的三行代码：

  • 重叠区中心：两张图离各自边界都远，w1≈w2≈0.5，均匀混合，看不出接缝。
  • 靠近接缝外侧：某一张的 d 趋近 0，它的权重也趋近 0，像素完全由另一张决定，不会出现"半透明的鬼影边"。
  • 非重叠区：只有一张图覆盖，另一张 d=0，权重自动退化为 1 和 0，也就是原样保留。

实现上就是两次 cv2.distanceTransform(mask, cv2.DIST_L2, 3)：把两张图各自的覆盖区域做成 0/255 掩码，距离变换后得到"离边界多少像素"的浮点图，相除即得权重。它比"按 x 方向做线性渐变"更通用 —— 不管重叠区是什么形状（倾斜、L 形、被裁掉一角），权重都是自洽的。

重要限制

羽化只能消除亮度的突变，不能修复几何错位。如果 H 不够准、两张图对不齐，融合出来的不是"平滑"，而是半透明重影——文字会出现双重轮廓。看到重影不要再调融合参数，回去查内点率、τ 和是否做了内点重算。

def stitch(img1, img2, H):
    h1, w1 = img1.shape[:2]
    h2, w2 = img2.shape[:2]

    # 包围盒：图1 四角经 H 变换后，与图2 四角求并集
    c1 = np.float32([[0, 0], [w1, 0], [w1, h1], [0, h1]]).reshape(-1, 1, 2)
    warped = cv2.perspectiveTransform(c1, H).reshape(-1, 2)
    c2 = np.float32([[0, 0], [w2, 0], [w2, h2], [0, h2]])
    allc = np.vstack([warped, c2])
    xmin, ymin = np.floor(allc.min(axis=0)).astype(int)
    xmax, ymax = np.ceil(allc.max(axis=0)).astype(int)
    ow, oh = int(xmax - xmin), int(ymax - ymin)

    T = np.array([[1, 0, -xmin], [0, 1, -ymin], [0, 0, 1]], np.float64)
    M = T @ H

    # 图1：变换到画布，同时得到它的有效区域掩码
    canvas1 = cv2.warpPerspective(img1, M, (ow, oh))
    mask1 = cv2.warpPerspective(np.full((h1, w1), 255, np.uint8), M, (ow, oh),
                                flags=cv2.INTER_NEAREST)

    # 图2：平移到画布（其余区域为 0），同样生成掩码
    canvas2 = np.zeros_like(canvas1)
    mask2 = np.zeros((oh, ow), np.uint8)
    ox, oy = -xmin, -ymin
    x0, y0 = max(ox, 0), max(oy, 0)
    x1, y1 = min(ox + w2, ow), min(oy + h2, oh)
    if x1 > x0 and y1 > y0:
        canvas2[y0:y1, x0:x1] = img2[y0 - oy:y1 - oy, x0 - ox:x1 - ox]
        mask2[y0:y1, x0:x1] = 255

    # 距离变换 → 羽化权重：离接缝越远，这一侧越可信
    d1 = cv2.distanceTransform(mask1, cv2.DIST_L2, 3)
    d2 = cv2.distanceTransform(mask2, cv2.DIST_L2, 3)
    total = d1 + d2 + 1e-6
    a1 = (d1 / total)[..., None]
    a2 = (d2 / total)[..., None]

    out = canvas1.astype(np.float32) * a1 + canvas2.astype(np.float32) * a2
    return np.clip(out, 0, 255).astype(np.uint8)

为什么用两次 warpPerspective 而不是"变换一张、再覆盖贴另一张"：融合必须拿到两侧各自的有效区域掩码才能算距离变换；覆盖贴图没有掩码，只能得到硬边。多出来的开销只是一次最近邻 warp 和两次距离变换，几千万像素也就几十毫秒。

四角的黑色不是 bug

透视变换后的图 1 是一个任意四边形，而画布取的是它的外接矩形，所以四角必然出现"两张图都没覆盖"的空隙，这些像素输出为 0（黑）。本机实测这块占整幅约 8%，视角越倾斜占比越大。这是拼接图的正常外观，不是融合失败；截图觉得难看就按有效区域裁剪一次。
